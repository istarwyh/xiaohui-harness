# XiaoHui Harness 0.2.6

## English

- Updates the bundled JavaScript Plugin and Python Adapter to Harbor Evolution `0.7.3` from the published npm and PyPI artifacts.
- Adds explicit credential-free Candidate `model-binding.json` identity, a Quick Diagnostic scaffold, active-project hot reload, Harbor 1.4 Task validation, and actionable Docker/ACP preflight failures.
- Shows bounded Host-side Harbor update checks without silently installing packages or restarting DSH, and follows the Plugin's explicit latest-runtime maintenance policy while requiring a fresh baseline after meaningful runtime drift.
- Retains the 0.2.5 desktop Host startup fix, Codex Auth, Better Sidebar, Personal Workbench, frozen offline Node dependency store, and portable Harbor Python runtime.

The application is not yet signed or notarized with an Apple Developer identity.

## 中文

- 从已发布的 npm 与 PyPI 产物把内置 JavaScript Plugin 和 Python Adapter 升级到 Harbor Evolution `0.7.3`。
- 新增不含凭据的 Candidate `model-binding.json` 身份、Quick Diagnostic 脚手架、活动项目热重载、Harbor 1.4 Task 校验，以及可操作的 Docker／ACP 预检错误。
- 由 Host 执行有时限的 Harbor 更新检查，不会静默安装 Package 或重启 DSH；同时采用插件显式声明的最新 Runtime 维护策略，并在出现实质 Runtime 漂移后要求新 Baseline。
- 保留 0.2.5 的桌面 Host 启动修复，以及 Codex Auth、Better Sidebar、Personal Workbench、冻结的离线 Node 依赖 Store 与便携式 Harbor Python Runtime。

当前应用尚未使用 Apple Developer 身份完成代码签名与公证。
